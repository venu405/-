# 任务 2: 采购方式区分

## 任务概览
- **任务主题**：单笔采购超过多少需要招投标？
- **任务目标**：区分政府采购与国企/企业采购的不同招投标门槛，避免混淆
- **检索查询**：政府采购公开招标数额标准、国有企业采购招标限额、非必须招标项目采购方式

## 来源概览
1. 云南中云招标咨询：浙江省货物/服务公开招标数额标准400万元（省、市、县三级统一）
2. 上海交大审计处（中国审计2024-15）：两法适用范围辨析，湖南限额标准（工程100万/货物50万/服务80万），《必须招标的工程项目规定》标准（工程400万/货物200万/服务100万）
3. 东北林业大学政府采购常见问题解答：中央预算单位公开招标数额标准200万元（货物/服务），分散采购限额（货物/服务100万、工程120万）
4. 中华人民共和国政府采购法（全文）：采购方式种类、公开招标数额标准制定权限划分
5. 国务院办公厅中央预算单位政府集中采购目录及标准（2020年版）：分散采购限额标准（货物/服务100万、工程120万），公开招标数额标准（货物/服务200万）

## 关键数据汇总
| 维度 | 中央预算单位 | 浙江省 | 湖南省（示例） |
|------|------------|--------|--------------|
| 分散采购限额（货物/服务） | 100万 | 各省自定 | 50万 |
| 分散采购限额（工程） | 120万 | 各省自定 | 100万 |
| 公开招标数额标准（货物/服务） | 200万 | 400万 | 各省自定 |
| 公开招标数额标准（工程） | 按国务院规定（400万） | 按国务院规定 | 按国务院规定 |

## 两法适用框架
- **政府采购法**：主体为各级国家机关、事业单位、团体组织，使用财政性资金
- **招标投标法**：适用于依法必须招标的工程项目（含国企资金控股/主导项目）
- 政府采购工程进行招标投标的，适用招标投标法（政府采购法第四条）
- 非招标方式：竞争性谈判、竞争性磋商、询价、单一来源
