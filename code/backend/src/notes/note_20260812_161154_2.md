# 任务 4: 例外情形界定

## 任务概览

**任务主题**：单笔采购超过多少需要招投标？
**任务名称**：例外情形界定
**任务目标**：识别哪些采购即使超过金额也可不招标（如紧急、专用、涉密等）

## 来源概览

1. **中华人民共和国政府采购法（修订草案征求意见稿）** - 单一来源采购适用情形（10项）、紧急采购程序、框架协议适用情形
2. **《政府采购非招标采购方式管理办法》财政部令第74号** - 单一来源采购适用情形（货物/服务3项、工程6项）、竞争性谈判、竞争性磋商、询价适用情形
3. **厦门大学招投标中心** - 单一来源采购的四种情形详细解读、专家论证要求、审批流程
4. **国标《电子采购交易规范非招标方式》要点解读** - 四种非招标采购方式（询比、谈判、竞价、直接采购）、国际比较
5. **政府采购非招标采购方式管理办法（全文）** - 非招标采购方式的程序性要求、审批流程

## 关键发现

1. 单一来源采购是金额超过招标标准后最常用的例外路径，涵盖专利/专有技术、紧急情况、原供应商添购（≤10%）、公开竞争失败等情形
2. 紧急采购（自然灾害、事故灾难、公共卫生事件等）可完全不执行招标程序，但需保存记录且不得排除竞争
3. 涉及国家安全、国家秘密、抢险救灾等特殊工程可不招标
4. 非招标方式国家标准（GB/T 43711-2024）确立了询比、谈判、竞价、直接采购四种方式
5. 例外情形均需履行审批/备案程序，且需专家论证
